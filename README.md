# HTTP, Fetch & Async JavaScript

Educational lecture materials (ლექცია 28–29) covering:
- HTTP fundamentals
- Fetch API
- Asynchronous JavaScript

## Overview

This project contains interactive educational content about HTTP requests, the Fetch API, and async/await patterns in JavaScript.

## Files

- `index.html` - Main lecture presentation with styled content and examples

## Getting Started

Open `index.html` in your web browser to view the lecture materials.

## Technologies

- HTML5
- CSS3 (with custom styling and Georgian fonts)
- JavaScript (Fetch API & async patterns)
- Google Fonts (Noto Sans Georgian, Noto Serif Georgian)

## Language

Content is in Georgian (ქართული).
